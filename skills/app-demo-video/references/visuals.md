# 分镜、视觉与导出参数

## 情景动画

- 开场问题段必须用场景动画，不得放 app 截图或鼠标箭头；只有转入真实功能演示后才显示鼠标。开场必须按内容分配约 10–15 秒，不能为了凑到某个整数秒数拉长每个入场动作。
- 必须为不同叙事对象使用不同的画面变化：建立工作环境可用安装卡片或工具落位，工作累积可用项目容器与任务卡片依次出现，回忆可用过去内容的片段，定位问题可用候选对象展开或聚焦，产品引出可用卡片收拢到品牌再揭示界面。必须选择能表达目标 app 问题的动作，不得照搬其他 app 的项目或会话概念。
- 安装示意必须只表示用户建立工作环境；当目标 app 没有安装其他工具的能力时，不得画成目标 app 替用户安装。候选项短暂高亮必须与真实选中状态可区分，不能让未完成的定位看起来已经成功。
- 默认必须采用 0.3–0.55 秒的入场、约 0.2 秒的错峰、约 0.22 秒的淡变和 `p * p * (3 - 2 * p)` 缓动，使用短距离位移、轻微缩放与有限旋转；不得使用持续弹跳或逐字蹦出的字幕。
- 旁白变长时，必须保持已经批准的安装、卡片弹出等入场节奏，用完成状态停留或新增有意义的动作承接后文；同一画面只换两句问题文字而没有语义对应变化时，必须重新设计分镜。

## 功能演示与画面证据

- 功能镜头必须录自实际 app；产品支持目标语言时必须切换为该语言，不支持时必须在 `brief.md` 说明保留实际界面，不得伪造产品本身不支持的本地化。必须使用隔离的演示数据，隐藏不相关窗口、通知和个人数据，并加轻量的 Demo data 标识。
- 必须先显示触发动作，再显示结果，并为结果留阅读时间。旁白说到的控件或结果必须在该句期间可见；字幕不必逐词驱动画面，操作开始点、关键结果和叙事转折必须与相应语义同步。
- 鼠标必须跟随真实操作坐标，使用约 0.45 秒的平滑移动和短暂点击提示；录屏缩放、裁剪或变速后必须同步变换鼠标坐标与事件时间。录屏已含鼠标时不得叠加第二个鼠标。
- 需要放大控件时必须固定锚点并避免镜头来回跳动，可从约 1.18 倍局部放大开始调整。恢复会话类功能必须显示真实复制命令动作及反馈；未获执行授权时不得执行命令，也不得伪造终端执行结果。
- 使用量、列表数量、日期和项目名必须来自同一份固定演示数据；台本需要展示使用量增长时，必须包含合理的高低波动、峰值与低谷，不能等差排列或每天重新随机。必须记录生成种子或数据版本，并检查汇总与分项一致。

## 默认视觉参数

必须在 1920×1080、30 fps 画布上采用下表默认值；修改比例时必须重新排版，不能直接裁掉信息。字号均为画布上的像素，界面录屏可读性必须在最终播放尺寸下检查。

| 对象 | 必须采用的默认值 |
|---|---|
| 背景 / 主文字 / 强调 / 次级文字 | `#f5f5f8` / `#332d3c` / `#8161a4` / `#786e82` |
| 容器 | 浅色圆角、轻阴影、克制的淡紫与淡蓝渐变 |
| 英文字体 | IBM Plex Sans；400、500、600 字重 |
| 中文字体 | Noto Sans SC；必须检查使用字符完整覆盖，不得因回退字体造成闪动 |
| 正文字幕 | 24 px、500、行高 1.4；底部 29 px，左右留白 128 px |
| 片头字幕 | 24 px；底部 36 px，左右留白 180 px |
| 主标题 / 章节标签 | 52 px / 14 px |
| 片尾网址 / 行动文字 / 署名 | 28 px / 20 px / 17 px |
| app 容器 | 左 128 px、上 42 px、宽 1664 px、高 936 px、圆角 17 px |

- 字幕必须按语义分块，最多两行；放不下时必须重分块，不得缩小到难以辨认。必须放在界面内容外的安全区域；品牌和片尾文字已传达同一句内容时，不得再叠加重复字幕。
- 必须在渲染前加载完本地字体和素材；英文版与中文版必须分别检查实际换行和控件遮挡，不能假定替换字符串后版式仍成立。

## 导出与异常定位

- 默认必须用 Remotion 单并发渲染连续 PNG 帧，再用 FFmpeg 编码：H.264、CRF 16、preset medium、yuv420p、30 fps、AAC 192 kb/s、48 kHz、立体声、`+faststart`。已批准的现有导出链未出现异常时，不得只为套默认值重编码无关素材。
- 必须将所有资源等待、时间轴帧索引和片段起止点固定，禁止在渲染函数中使用未固定种子的随机数、当前时间或未等待的字体加载。
- 检查闪帧时必须结合相邻帧差与前后帧相似度生成候选；检查固定边缘时必须按镜头分段建立基线。转场、点击高亮或真正的页面切换不能仅因差值大就判错；必须查看候选帧前后的连续画面。
- 拼接必须核对最后一帧、下一段第一帧与时间戳，避免重复帧、丢帧或短暂跳回旧页面；局部替换必须同时检查两侧的声音连续性。
